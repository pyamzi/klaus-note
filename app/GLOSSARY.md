# KlausNote

Language for Note editing. Existing domain terms retain their definitions in [CONTEXT.md](CONTEXT.md).

## Language

**Note editing**:
Entering or changing a Note's field values and tags. Creating a new Note and updating an existing Note remain distinct actions.
_Avoid_: Card editing (for changes to Note fields)

**Note draft**:
Field values and tags prepared for a new Note, or unfinished changes to an existing Note. A draft can differ from the Note already stored in the Collection.
_Avoid_: Card draft
